## ⚙️ Customization Guide

When your token goes live on [pump.fun](https://pump.fun):

1. **Contract Address (CA)**:
   Open `index.html` and replace `BurnPumpFunXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX` with your official Solana token mint address.

2. **Social Links**:
   Update the button links in `index.html`:
   - `https://pump.fun` ➔ Your token URL on pump.fun.
   - `https://x.com` ➔ Your official X (Twitter) profile.
   - `https://dexscreener.com` ➔ Your DexScreener chart URL.

## 💻 Local Development

To run the site locally:
```bash
# Using Python:
python -m http.server 3000

# Or with Node.js:
npx serve .
```
Then visit `http://localhost:3000` in your browser.
